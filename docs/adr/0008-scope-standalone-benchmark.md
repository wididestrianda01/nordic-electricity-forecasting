# Scope P14 as a standalone benchmark, not a P16 feeder

P14 was first scoped as the forecast-input layer for P16 (the BESS revenue
optimizer). The project was recast as a standalone, recruiter-facing benchmark
that compares ten forecasting models on a defensible methodology. The reason is
that a complete benchmark, with a full model comparison and a documented
methodology, is more useful on its own than a narrowly scoped feeder.
